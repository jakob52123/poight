# VH 主角八招：物理不动，只替换外观

## 边界与接入

新增 `主角招式外观.js`，由 `招式动画/打包.py:runtime()` 拼入候选；`构建完整版.py` 的来源清单同步登记。没有改 `游戏数据.py`、身体系统、伤害/射程/冷却、八方向逐帧嘴/颊/尾/爪/翼锚点或原物理判定。

- 外观按「招式 ID + 所属主角」双重 opt-in：皮卡丘四招只对 #25、喷火龙四招只对 #6 启用。其他精灵使用同名招式保留既有路径，防止缺少主角解剖锚点时误接入。
- `prepare` 只保存既有 `originAnchor`，不覆盖弹体参数或锚点。
- `bullet` 以既有弹体为前沿；电束与火柱连到实时颊/嘴锚点。不是 instant ray，不增加伤害次数。
- 近战仍由原 melee 分支判伤；尾部金属光泽经原 `tailMask` 裁到当前角色帧，尾弧跟随逐帧尾锚。龙爪小气刃跟随前爪，三道完整爪痕只在真实成功 damage 的接触点按 0/.04/.08 秒依次出现；使用原版 `claw_slash` 最后一帧，保留白描边，内部由 #7b5cff 经高饱和中间色过渡至 #6ff0ff。三道屏幕斜向平行，间距至少18世界像素，持续到 .18 秒后才淡出，不叠毛絮粒子。
- 打雷仍使用原 `windup + delay` 和固定 `targetPoint`。警告有上方亮点、地面黄虚线圈；仅 `landed` 时从真实 Canvas 相机变换逆算的可视上边缘落下，8段向下锯齿、3短分叉、.30施放者身高黄外晕与白芯，三个30Hz相位亮/暗/亮。主干在人物下层绘制；地面黄白中空电环在上层绘制，最大外径不超过1.3目标身高。躲离原判定范围仍不会掉血。
- 命中外观仅为主角打雷/龙爪的成功命中替换通用实心星：前者由落地环给出可见接触，后者由第一道爪痕给出可见接触；核心 contact/burst 事件及伤害时钟仍保留。其他招式的通用星不改。打雷成功后目标按当前帧 alpha 掩模闪两次窄白条，保留大多数原色；不再同时套原亮度滤镜。顿帧由原系统自然消耗，白条/落雷/爪痕均用模拟时钟。
- 大字爆炎始终为原直线单弹体，命中/撞墙立即销毁物理弹；五向爆开为没有伤害能力的短命视觉。五火团坐标不随飞行方向旋转，保持「大」字可读。
- 电光一闪不做 Showdown 往返/瞬移：沿用真实 rush 位移和真实历史位置残影，只加强残影透明度及白速度线。
- `?anim=old` 回到既有 M4/B1 表现。核心三样板和 B1 牙齿路径不变。
- 所有状态由模拟 dt 驱动；顿帧、暂停时一起冻结，reset 清空。没有在 draw 中判伤。

## 原版来源与保护

亲自读取八张 ref-moves 卡片、对照表对应条目、绿宝石八段脚本，以及 V1p 读图记录。借用电花/电球、火苗、金属闪光意向、爪痕和旋风刀月牙；空气斩没有第三代同名动画，不冒称原版同名复刻。没有调用生图或付费 API。

新增副本见 `原版/VH来源.json`，逐文件 SHA 在新增验收里检查；只在构建内存中裁切/调色，原版副本字节保留。**八招原图集均未替换**，因此所有原八招 SHA 守卫原样保留、没有旧 SHA→新 SHA 迁移。尖石攻击仍必须是 `ec3849ad57d94f0a64a8b95e2f9e188051659d7eb0f5ccc2b836f6684c66ed39`。角色和地图资源不变。

## 像素验收口径

`验收-主角八招.py` 原有锚点、冷却、前摇、真实位移、射程、撞墙、世界边界、落点延迟/闪避断言全部保留。160 次连续飞行采样改为在同一个 page.evaluate 里收集，采样频率、数量、方向检查不变，不通过减少采样来提速；仅跳过无截图需求的中间重绘，采样帧和实际命中帧均调用真实 draw。

新增 `tests/主角动画像素.js` 镜像**生产 paint 调用**的实际 Canvas 变换；不使用替代绘制器，不传入测试专用颜色/尺寸。两张正式地图 × 八招 × 八方向，保存 composite/background/mask。主体阈值 alpha≥250，逆变换回世界像素：

- 光束测中段八个法向截面的最小宽度 ≥max(10,.30H)，中心亮度≥230。
- 大字爆炎主体宽高≥.70H，截获实际五次火苗贴图绘制并分别量化不透明像素中心；断言顶点、等高双臂、分离双腿、左右对称、火团间距。
- 打雷保留实际不透明高度≥3H、横向跨度≥.35H，并新增顶部实际像素抵达可视边缘；截获真实描线调用检查8段单调下落折线、3分叉、主干宽.25–.35H。落雷不透明像素时序必须亮/暗/亮。
- 目标原色保留率逐120Hz模拟帧测到 .342秒：镜像当前目标实际 sprite 像素并施加同一次竞技场镜头震动，和最终游戏画布逐像素对齐；在原始不透明目标掩模（位于其包围盒内，不用空背景充数）内，RGB各通道差≤8的像素比例≥50%。地面环中心无实心像素、外径≤1.3目标H；镜像实际白条绘制确认只出现两次。
- 龙爪保留首次爪痕≥.70×目标H，新增从0到.10秒逐帧8邻接连通域检测，按0/.04/.08秒必须依次1/2/3条，每条实际不透明长≥.80目标H、法向宽≥4世界像素。铁尾/速度线行动主体≥max(14,.30H)；空气斩法向跨度≥max(14,.45H)。银白/纯白专用招式不要求属性饱和度，其余属性像素平均 S≥.55、覆盖≥30%。
- 主体与同位置背景平均亮度差≥60；不是用外晕或透明框充数。站位取正规场红土/自然场草地，避开正规场中心的白色队徽，不换第三张低亮背景。
- 打雷/龙爪在首次命中帧测量；背景层屏蔽同一招自己的特效，不将其他特效当成背景。其他招式在真实接触前一tick测量。
- 逐120Hz tick找首次真实HP下降，比较事件时钟，并镜像实际命中外观的opaque raster：打雷电环、龙爪第一道爪痕，其他六招仍为通用星。打雷电环年龄以原landed阈值为原点，允许落地积分余数0–1/120秒；其余仍严格age=0。不是仅检查配置中的impactMs，也没有延后原伤害。

GIF 为真实游戏按40ms步长推进、每帧40ms的25fps原速录制；每招横/斜两站位各1.64秒，包含顿帧。四时刻为前摇、实际接触前1个120Hz tick、首次命中、命中后；龙爪第四格/特写明确取顿帧结束后模拟时间+.09秒三爪齐出，M4对照也取完全相同墙钟tick；打雷录像扩大取景以保留真实镜头顶端，不能用旧270px裁切截短雷柱。3倍特写不用于尺寸验收。M4 对照代码从 git 固定提交 `f64982be201b70212a8a6b3e0ff5fad6618f6cad` 提取，不以当前 `anim=old` 冒充历史版本。对照页共享的八招图集与玩法数据未变。
