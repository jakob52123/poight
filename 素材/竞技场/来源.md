# 竞技场美术来源

六张竞技场原图由本项目使用 Codex 图像生成方式制作，再自行加工为像素竞技场；不是从宝可梦原版地图或贴图中提取。
正规场与自然场各含 A/B/C 三个版本。保留原图，并提供扩建后的六张运行图与碰撞/草丛标注。

扩建加工脚本：仓库根目录 `扩建竞技场.py`。它从原图裁切、用最近邻重采样并拼接地面/看台/树墙，重绘场地线与中心标志，按像素坐标生成障碍、草丛及出生点标注；不使用角色素材，也不拉取原版地图。

扩建图为 1050×700 美术像素，对应 2100×1400 世界像素。
